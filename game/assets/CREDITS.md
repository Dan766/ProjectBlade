# Asset credits

Every third-party file shipped with the game is listed here (source, author, licence). Rule: CC0 / OFL
or similarly permissive only, and each download approved by the user (see `docs/specs/graphics.md`).

Models, terrain, scatter, settlements and parties are generated in code (`game/scripts/map3d/`) and
need no credit.
